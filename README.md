# 🦀 crab (forked by w1nOS)
**crab** is an open-source CLI tool for working with files, originally created by w1n4a in 2026 and modified by the w1nOS Team.

### Commands:
```crab
help — Show this menu (--help)
ls — Print a list of files
copy — Copy file to a new path
slice — Print a slice of file text
move — Move a file to a new path
read — Read file/files
del — Delete files/symlinks/dirs
mkdir — Create dir/dirs
mkfile — Create file/files
lines — Print file content with line numbers
write — Overwrite file
find — Find text in the file
count — Count occurrences of text in a file
mask — Mask text in file
len — Print length of file text
len-lines — Print number of lines in a file
reverse — Print reversed text of file
reverse-lines — Print reversed lines of file
watch — Watch file changes: <mode> <file>
  -n: bell notification
  -r: read
  -rl: lines
  -l: len
  -ll: len-lines
  -rv: reverse
  -rvl: reverse-lines
```

### Usage:
 ```crab
crab <command> <path or args>
```

### Install (for w1nOS):
```w1n
w1n ins crab
```
